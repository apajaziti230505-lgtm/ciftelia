# Projekti Android (Android Studio)

Hape dosjen `android` me Android Studio, sinkronizo Gradle dhe zgjidh **Build → Build APK(s)**. Pritet Android SDK 35, JDK 17 dhe lidhje interneti për varësitë Gradle. Projekti nuk është APK i ndërtuar dhe nuk është testuar në telefon; është një WebView që hap GitHub Pages, prandaj kërkon internet. Leja e mikrofonit jepet vetëm për origjinën e faqes së çiftelisë. Për instalim pa ndërtim përdor PWA në Chrome Android.
